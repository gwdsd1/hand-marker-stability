# 掌根与拇指稳定性优化报告

2026-10-22。本轮采用`guarded_axes_v3`作为新的左手审阅版，右手沿用基线。按用户最新口径，接受很小轮廓指标退步，实际视觉不能明显变差。六段视频已生成并复查；旧冻结目录与生产默认不覆盖。此处为左手MANO叠加研究结果，未重建本轮完整人体/扫描物体互动视频。

## 查出的原因

掌根可见抽动包含两件不同的事：世界腕根运动，以及MANO在手局部坐标中的网格形变。固定root后改变拇指姿态，MANO姿态修正与蒙皮仍会影响掌根/鱼际。反事实诊断把拇指固定后，掌根局部加速度P95从0.215866降到0.039897m/s²；这支持拇指变化是重要贡献，但不是演员运动真值，也不是采用“锁死拇指”的方案。官方MANO与当前前向实现数值核对通过，没有发现实际LBS坐标实现错误。

拇指三个局部关节有9个旋转参数，两个marker位置对某些轴向旋转与关节组合约束不足；marker位置贴合仍允许不同骨架/网格姿态。旧解可在弱观测方向上用轴向旋转作补偿，继而牵动掌部。MCP/IP骨轴目前来自共享beta下的MANO模板轴，不是独立测得的演员功能轴。因此只能说明低观测补偿存在，不能把所有偏差归罪于marker噪声或某一块骨长。

稳定掌参考的独立试验也完成了：只有两个背侧掌点时刚体参考雅可比秩5，6维刚体位姿中绕两点连线的旋转无法单独观测。原生两掌点距离P95−P5约3.929mm，不能简单视作完美刚体。使用冻结腕Q加两掌点重估root，虽使腕根加速度P95略降5.267→5.204m/s²，却使原生marker P95从6.073升到10.255mm、最大16.686mm，因此拒绝。腕Q本来也是条件估计，不是独立前臂真值。

## 采用的算法修改

固定世界root、其他四指pose、共享beta、贴面偏心安装、高度、腕Q和最新外参。共享手型本轮作为固定约束，没有再次通过改beta吸收姿态误差。手部marker保持10mm背侧半球及原始来源。

对拇指使用约束流形优化：保持两个拇指marker的预测坐标，以及IHAND到实际C3D点的残差模长；梯度先投到约束雅可比的零空间，每步再做非线性约束恢复。这样主要利用原本弱观测的自由度，降低局部掌根网格加速度和MCP/IP轴向补偿，并约束SO3姿态变化。不是给全手再加一层强平滑，不改安装偏移，也不锁死正常CMC对掌。

参数跨634时刻统一，150步、掌局部项权重10、轴向项30，无逐案例手调。优化后用纯三维统计逐次自动回退整帧候选并重新检查时间邻域；最终522时刻采用候选，112时刻pose精确沿用基线。RGB/depth均不进入pose损失或逐帧回退选择；RGB只在最后选整套候选时离线核对。

## 未采用的试验

独立掌参考重定位root因marker明显恶化拒绝。未保持IHAND残差的早期零空间版本、未经回退的时序版本会损伤其他marker或增加极端角步变，拒绝。连续分支重初始化后只剩3时刻可通过保护，收益不足。限制只处理旧观测修复区及其保守缩步版本，改善明显弱于最终方案。

更强的残差等模长方案允许预测点在等残差球面内移动；`minimum_compensation_v9`原始候选曾将最大拇指步变压到102.662°，但其他动态统计回退，保护后又回到134.521°。保护版只保留45时刻，掌根P95约0.215160、拇指P95约19.1905°，综合不如采用版；它的MCP轴向P95更好，但没有足够理由牺牲主要掌根稳定收益来替换。以上为被拒/未选开发候选，不混入成品。

## 仍有欠缺与下一步

本轮实现的是温和、可保护旧结果的改善。世界腕根抽动与极端拇指分支仍未解决，IP轴向补偿残留较大。视频仍能看到鱼际、掌宽、指甲及快动模糊段不完全贴合，不能把marker残差当作真实表面准确率。半球光学中心相对底面的0mm假设、同步、真实关节轴与骨长仍缺独立认证。也没有开展右手新认证或完整互动碰撞验收。

优先下一步是增加真正可独立约束的稳定掌/前臂参考，例如三点不共线的稳定簇；用单独拇指屈伸、外展/对掌动作辨识共享功能轴与安装不确定性，保持RGB仅校正共享shape。对25.1367→25.2067秒极端分支，需在纯C3D候选图中联合选择整段连续分支，并单独报告各观测可辨识性，不能再用更强平滑抹平。共享骨长/手型与功能轴应在分离标定阶段检验，避免与安装高度继续互相补偿。
