# 验收口径与局限

本轮沿用同一capture、同一634开发时刻与相同观测；这是开发验收，不是新鲜留出测试。RGB既不优化pose/root/安装，也不逐帧决定哪个pose采用，只用于整套候选离线评估和视觉审阅。

统一检查586项：367项非图像硬检查全部通过；219项图像代理保留严格差异。其中17项未满足旧的近乎逐数值不退化要求。本轮按用户最新要求允许很小轮廓退步；数值初筛0.5像素、IoU绝对0.003不是实测精度或用户指定数值，仍有5项触发提醒，已独立查看对应14.4067/20.2067秒原RGB/上一版/候选同帧图，以及六段最终MP4的48张解码抽帧，未发现明显新增退化。未隐藏或把这17项改写为严格通过。详情`adoption_guarded_axes_v3_gate.json`及`VISUAL_REVIEW_RECORD.json`。

图像代理来自自动分割，模糊、背景、指甲和遮挡会影响尾部值。14秒轮廓尾部最大值103.464→106.033px；19秒组轮廓P95中位数25.025→26.162px、IoU最高统计0.824530→0.818382，这些变化全部留账。对应手型与姿态在同帧对照里没有明显新增畸变，不表示这些RGB本身已经准确贴合。

手指固定评估记录共202条：index35、middle54、ring58、pinky55。历史summary的167是middle/ring/pinky三指汇总、31个RGB时刻，不能误写为四指总数。summary固定167条的中心/边缘统计本轮精确不变。侧视15帧轮廓中位数8px不变，P95为12.671→11.830px；不是多相机真值或每个侧视都改善。

局部掌根验收区81顶点采用沿用的模板顶点相对演员腕中心距离<45mm、root权重>0.9；优化器则按演员shape后的距离选77顶点。两套索引均跨所有候选固定，验收区与优化区不完全相同，不能混称同一77点集合。81点局部加速度P95为本报告主指标，不是世界腕根平移加速度。时间差>=0.12秒的间隙不计算相邻动态项，角步变度数也不是角速度。

纯三维回退保护的是约定统计及邻域；不保证每一个顶点/点残差都逐元素不退化。拇指两marker预测坐标约束、IHAND残差模长约束保持数值精度；其他marker会因MANO姿态修正发生轻微变化。原生各区域/各片段统计仍在0.001mm容差内，真实毫米级观测/建模误差没有因此消失。

4项数值测试验证标准MANO与自定义LBS一致、子集前向一致、约束零空间和非线性恢复。官方MANO平移应为world wrist减去shape后的J0，已核验，未发现实际前向模型根坐标错误。29个交付Python源码通过AST与本地导入闭包检查。新兄弟副本重放6阶段并核对关键输出，详情`replay_final_verification.json`。

最终六MP4共581帧完整解码；视觉实际检查48个抽帧及8张同帧诊断图，另有早期2张静态图。抽帧不能认证每个瞬间无抖动。左右手碰撞、完整人体/扫描物体交互、右手新认证、物理光学中心与硬同步都未在本轮完成。
